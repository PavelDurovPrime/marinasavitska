# Налаштування власного домену для сайту на GitHub Pages

Цей посібник містить покрокову інструкцію, як підключити власний домен (наприклад, `marinasavytska.com` або `marinasavytska.com.ua`) до вашого сайту, що зараз розміщений на GitHub Pages.

---

## Крок 1. Створення файлу `CNAME` у проекті

Щоб GitHub Pages знав, на який домен перенаправляти користувачів:
1. Створіть файл з назвою `CNAME` (великими літерами, без будь-якого розширення, наприклад, `.txt`) у кореневій папці вашого репозиторію.
2. У першому і єдиному рядку цього файлу запишіть назву вашого домену.
   * *Наприклад:* `marinasavytska.com` (або ваш точний куплений домен).
3. Збережіть файл та відправте (commit/push) його до репозиторію на GitHub.

> [!TIP]
> У цьому репозиторії вже створено шаблонний файл `CNAME`. Вам достатньо просто відкрити його та замінити поточний текст на ваше куплене доменне ім'я.

---

## Крок 2. Налаштування DNS-записів у реєстратора доменів

Перейдіть у панель керування сайту, де ви придбали домен (наприклад, NIC.ua, Hostinger, Namecheap, GoDaddy тощо), знайдіть розділ **Керування DNS** (DNS Zone Editor) та додайте такі записи:

### 1. Налаштування основного домену (Apex domain, наприклад, `marinasavytska.com`)
Додайте чотири **A-записи**, які вказують на IP-адреси GitHub Pages:

| Тип (Type) | Хост/Subdomain (Host) | Адреса/Значення (Value/IP) | TTL |
| :--- | :--- | :--- | :--- |
| **A** | `@` (або залиште порожнім) | `185.199.108.153` | Авто / 3600 |
| **A** | `@` (або залиште порожнім) | `185.199.109.153` | Авто / 3600 |
| **A** | `@` (або залиште порожнім) | `185.199.110.153` | Авто / 3600 |
| **A** | `@` (або залиште порожнім) | `185.199.111.153` | Авто / 3600 |

### 2. Налаштування піддомену `www` (наприклад, `www.marinasavytska.com`)
Додайте один **CNAME-запис**, який зв'язує піддомен `www` з вашим основним профілем GitHub Pages:

| Тип (Type) | Хост/Subdomain (Host) | Адреса/Значення (Value) | TTL |
| :--- | :--- | :--- | :--- |
| **CNAME** | `www` | `paveldurovprime.github.io.` | Авто / 3600 |

> [!IMPORTANT]
> Переконайтеся, що значення запису CNAME закінчується на `paveldurovprime.github.io.` (деякі реєстратори DNS вимагають крапку наприкінці, деякі додають її автоматично).

---

## Крок 3. Налаштування в інтерфейсі GitHub

Після налаштування DNS-записів та відправки файлу `CNAME`:
1. Відкрийте ваш репозиторій на **GitHub**.
2. Перейдіть у розділ **Settings** (Налаштування) у верхньому меню.
3. У лівій панелі натисніть на вкладку **Pages**.
4. У розділі **Custom domain** введіть ім'я вашого домену (наприклад, `marinasavytska.com`) та натисніть кнопку **Save**.
5. Зачекайте завершення перевірки DNS (зазвичай це триває від 5 хвилин до кількох годин, інколи до 24 годин).
6. Після успішної перевірки з'явиться можливість увімкнути прапорець **Enforce HTTPS** (Обов'язкове використання HTTPS). **Обов'язково ввімкніть його**, щоб ваш сайт мав захищене з'єднання (іконку замочка в адресному рядку браузера).

Сайт буде успішно підключено та оптимізовано для пошукових систем за новою адресою!
